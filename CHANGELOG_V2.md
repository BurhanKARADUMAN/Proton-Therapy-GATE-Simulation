# Bragg Peak Lab — Version 2.0 research upgrade

Added an independent, well-documented toy 1D residual-energy model, energy and material sweeps, range uncertainty study, SOBP energy-layer optimisation, strict GATE MetaImage loader, command-line interface, interactive Streamlit demo, unit tests, GitHub Actions and reference-based caveats.

Historical GATE macros, report, and figures are not modified by this update; all new generated curves are transparently identified as demonstration results rather than validated Geant4 dose maps.
